# NUVIA для Android

NUVIA — бесплатный музыкальный плеер без рекламы. Слушайте свою музыку из ВК, добавляйте песни с телефона и сохраняйте треки для прослушивания без интернета.

**[Скачать NUVIA 0.7.0 для Android](https://github.com/juice789-code/NUVIA-updates/releases/download/v0.7.0/NUVIA-0.7.0.apk)** · [Все выпуски](https://github.com/juice789-code/NUVIA-updates/releases)

Если NUVIA уже установлена, откройте **Настройки → Обновления NUVIA → Проверить обновление**. При первой установке скачайте APK по ссылке выше и откройте его на телефоне.

## Что изменилось в 0.7.0

- После быстрой прокрутки «Моей музыки ВК» песни запускаются быстрее. Плеер заранее запрашивает ссылки для видимых треков.
- В поиске можно переключаться между «Мои треки» и «Весь ВК». Если у песни несколько исполнителей, нажмите на их имена в плеере и выберите, чьи популярные песни открыть.
- Всю «Мою музыку ВК» можно поставить на скачивание одной кнопкой. В очереди видны обложки и прогресс. Загрузку можно приостановить, а отдельный трек — пропустить.
- Сканирование телефона позволяет выбрать аудиофайлы для добавления в медиатеку.
- В очереди воспроизведения видны название и исполнитель следующей песни. Текст открывается на весь экран и подсвечивается, если для песни есть таймкоды.
