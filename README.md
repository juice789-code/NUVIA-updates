# NUVIA — обновления

Публичный канал APK и описаний обновлений NUVIA. Исходный код приложения хранится отдельно в закрытом репозитории.

Обновления можно будет устанавливать прямо из NUVIA 0.4.0. Для первого перехода со старой версии скачайте подписанный APK из Releases и установите поверх прежней NUVIA.
