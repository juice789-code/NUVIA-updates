# NUVIA 0.6.4

- Исправлена обработка запоздавших событий загрузки страниц ВК: старый ответ больше не должен обрывать новый запрос.
- Расширена поддержка адресов музыкальных страниц и списка плейлистов; для неподдержанного перехода отображается безопасная категория ошибки.
- Обновление обложек отделено от загрузки аудио. Добавлены форматы ссылок и точечный запрос метаданных трека из ВК, в том числе для песни из поиска.
- Свежая ссылка применяется к текущему плееру, даже если трек ещё не добавлен в медиатеку.
- Добавлен автоматический запасной поиск по исполнителю и названию через MusicBrainz / Cover Art Archive. Только точные совпадения; временный локальный кэш. Можно отключить в «Обложки и фон».
- В «О приложении» добавлен канал t.me/nuviamuz.

Устанавливайте поверх текущей NUVIA. Данные входа ВК внешним сервисам обложек не передаются; поиск использует название песни и исполнителя.

Исправления проверены автоматическими тестами. Работа с реальным аккаунтом ВК и телефоном ещё не подтверждена. MusicBrainz на проверочном компьютере не ответил за 20 секунд; доступность сервиса зависит от сети. Если подходящая обложка не найдена, остаётся фон. Это тестовый выпуск, не обещание доступности всех подборок ВК.
