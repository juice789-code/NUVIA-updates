# NUVIA 0.6.8

- «Моя музыка» показывает песни с первой страницы, пока ссылки на воспроизведение ещё не нужны. При нажатии NUVIA готовит выбранный трек и ближайшие следующие. Новая страница загружается при прокрутке или по кнопке.
- Возврат из общего поиска сохраняет список и его фильтр. В поиске появились недавние запросы, повтор одним нажатием и очистка. Из меню песни можно найти исполнителя.
- Долгое нажатие включает выбор до 20 песен. Их можно добавить в NUVIA одним действием. Нажатие на заголовок длинного списка возвращает к началу.
- В «Моей музыке» появились «Друзья ВК» и открытие музыки по числовой ссылке на профиль или сообщество. В плейлисте можно нажать на владельца. Видимость чужой музыки зависит от ВК. Раздел друзей и страницы профилей нужно проверить на реальном аккаунте.
- Найденная обложка выбранной песни сохраняется на устройстве и используется при повторном открытии.

Устанавливай поверх текущей версии. Это пробный выпуск для проверки нового сценария на телефоне.
