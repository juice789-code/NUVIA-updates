# NUVIA0.6.1

- Компактный поиск: автоматический запрос после короткой паузы или кнопка клавиатуры.
- Песни обычным списком; нажатие сразу играет. Отдельное меню: добавить в медиатеку, свой плейлист, сохранить без интернета.
- «Моя музыка ВК» доступна с главной; слушать можно без обязательного копирования всей музыки. Локальный поиск по полученному списку, обновление и переход ко всему поиску ВК.
- Мини-плеер, очередь из соседних песен, нижняя навигация. Возврат из поиска/полного плеера сохраняет список и фильтр.
- Защита от устаревших результатов при изменении запроса и от повторных фоновых запросов.

Переработан интерфейс и сценарий. Источник остаётся сохранённым вебсеансом ВК; официальный музыкальныйAPI не подключён. Первоначальное получение каталога может занимать время; доступ и воспроизведение требуется проверить на телефоне. Демонстрационные песни в приложение не добавлены.

Проверки:92Android/Robolectricтеста,lint0ошибок,APKподписьv1/v2и прежнийсертификат,manifest/DEX/ресурсы. Снимки интерфейса — технические fixtures, не живой аккаунт. Исходники закрыты, ключи/пароли/cookies/токены не публикуются.
