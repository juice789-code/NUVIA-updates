# NUVIA 0.4.1 — новые настройки

- Полноценная страница настроек в графитово-мятном стиле с группами разделов и плавными переходами.
- Автокэш, обновления и память открываются отдельными страницами. Настройки сохраняются сразу.
- «О приложении»: актуальная версия, разработчик **Команда NUVIA**, информация о приложении без рекламы и рекламных заработков.
- «Поддержать NUVIA»: добровольная благодарность через Т-Банк, кнопка копирования номера карты. Все функции доступны без доната.
- Сохраняется открытая страница настроек при пересоздании приложения. Анимации учитывают системные настройки.
