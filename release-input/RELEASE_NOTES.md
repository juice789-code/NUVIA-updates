# NUVIA 0.5.0

Новый экран загрузки и проверки обновления
Автокэш без лимита объёма, ручная очистка музыки
Очистка медиатеки и плейлистов, сверка импорта ВК
Поиск музыки ВК через сайт и выбор результатов
Настоящие обложки и жанры из тегов, пресеты эквалайзера

Слово «офлайн» заменено на «Загружено», «Скачать» и «без интернета». Автоматически музыка не удаляется. При нехватке памяти скачивание приостановится.

Поиск использует настоящую форму сайта ВК; доступность зависит от аккаунта и разметки сайта. Если подходящая форма или результаты недоступны, приложение показывает отказ. Живая сессия не проверена нами. Обложки берутся из предоставленных ВК URL, жанры — из тегов локальных файлов при наличии; жанры не угадываются.

54 теста, lint без ошибок; сохранена прежняя подпись. На телефоне требуется проверить поиск/импорт, звук, загрузки и установку. Устанавливать поверх предыдущей NUVIA без удаления приложения.
