## Что нового в NUVIA 0.7.0

- Быстрее запускаются треки после прокрутки «Моей музыки ВК».
- Переключайся между поиском по своим трекам и всему ВК.
- В очереди скачивания видны миниобложки. Загрузку можно приостановить, отдельный трек — пропустить.
- Сканирование телефона помогает добавить местную музыку в медиатеку.
- Обновлён плеер и добавлен полноэкранный текст песни.
