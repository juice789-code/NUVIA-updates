# NUVIA 0.6.5

- При добавлении песни запускается загрузка обложки; полученная картинка сохраняется с треком на устройстве и доступна без интернета. Музыка добавляется сразу, поиск картинки идёт в фоне.
- Добавлен запасной поиск обложек Deezer с проверкой исполнителя и названия. Названия сборников вроде «XXXL 1999» отделяются от названия песни; ремиксы не подменяются оригиналом. Проверен реальный ответ для «Моя Сирин — Юля Паршута».
- Внешние запросы содержат только исполнителя и название; вход ВК не передаётся. Поиск можно выключить в «Обложки и фон».
- Расширен разбор встроенных данных «Подборок». Живая работа подборок на аккаунте ещё требует проверки; при неподдержанном ответе музыка не подменяется своей медиатекой.

Устанавливайте поверх текущей NUVIA. Наличие обложки для каждой песни не гарантируется: оно зависит от данных ВК, внешнего каталога и сети.
