# NUVIA 0.5.3 — проверочный выпуск

- Автоматическое обновление ссылок обложек через вход ВК
- Исправлена обработка ссылок с параметрами и очередь картинок
- Новый экран эквалайзера: график, пресеты и вертикальные полосы
- Статус загрузки и повтор по нажатию на обложку
- Доступ к обложкам зависит от сеанса и ответа ВК

Автообложки: только пока приложение открыто, с ограничением частоты, через сохранённый сеанс ВК. Кнопка ручного обновления не нужна для обычной попытки. Может потребоваться повторный вход. Источник — раздел «Моя музыка» аккаунта; треки вне него могут не найтись.

На настоящем телефоне получение обложек и звучание EQ ещё требуют проверки. 77 автоматических тестов прошли; данные/скриншоты тестов не выдаются за реальный ВК. Если картинки нет, нажать крупную обложку песни и посмотреть безопасный статус.

Полностью родной каталог/поиск/рекомендации ВК ещё не реализованы: прежние ручной импорт и web-поиск могут открыть сайт. Служебный сеанс для автообложек не отображает страницу. Темы и лента подборок отложены.

Устанавливать поверх текущей NUVIA, не удалять приложение. Исходники остаются закрытыми.
