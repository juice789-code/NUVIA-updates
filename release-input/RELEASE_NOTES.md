# NUVIA 0.5.2

- Исправлена смена фонов: автоматически и по нажатию
- Найденное обновление запоминается после перезапуска
- Проверка при открытии с интервалом 15 минут
- Новое окно с версией, описанием и кнопкой обновления

Фон переключается каждые 12 секунд, можно нажать на баннер. Отключённые системные анимации больше не блокируют смену картинок. Автосмена имеет свой выключатель. Обложки песен зависят от данных ВК; случайные изображения не выдаются за обложки.

Для получения этого выпуска из0.5.1 нажать «Настройки → Обновления NUVIA → Проверить обновление» — в прежней версии ещё действует суточный интервал. Установить поверх текущего приложения, не удалять NUVIA. Установку подтверждает Android.

69 автоматических тестов, lint без ошибок; на физическом телефоне требуется проверка. Исходники закрыты, APK доступен всем.
