# NUVIA 0.6.10

- Прокрутка списка, поиска и плейлистов требует меньше работы на каждом кадре.
- Недостающие обложки запрашиваются отдельно после появления списка. При недоступной картинке Deezer пробуется второй источник.
- Сообщение об ошибке в «Друзьях ВК» остаётся на экране и позволяет повторить запрос.

Прокрутка проверена на POCO в тестовой сборке. Финальный APK прошёл локальные проверки. Две контрольные обложки в тесте на телефоне оставались заглушками. Ошибки получения друзей и подборок ВК пока остаются.
