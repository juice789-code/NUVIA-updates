# NUVIA 0.5.1

- Меняющийся баннер с обложками и пейзажами, карточки плейлистов с воспроизведением.
- Новый экран поиска: слушать, ставить на паузу и добавлять песни по одной.
- Импорт по умолчанию только из «Моей музыки» ВК, с подтверждением списка. Другие плейлисты импортируются отдельно.
- Настройки обложек из интернета и обновление картинок ранее добавленных треков без изменения состава медиатеки.
- Единый графитовый стиль окон, мятные кнопки и аккуратные поля.
- «Предложения и проблемы»: черновики обращений GitHub и копирование краткого отчёта.
- Убрана лишняя подпись под баннером плейлистов.

Доступность поиска, импорта и обложек зависит от сайта ВК и прав текущего аккаунта. Это тестовый выпуск: работа с живым аккаунтом и установка на телефоне требуют проверки. Темы пока отложены.

Устанавливать поверх прежней NUVIA, приложение не удалять. Установку подтверждает Android. Исходники закрыты; APK доступен всем.
