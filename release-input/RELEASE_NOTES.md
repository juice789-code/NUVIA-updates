# NUVIA 0.4.0 — автокэш и обновления

- Автокэш: шестерёнка → Автокэш → включить сохранение. Полная загрузка после 10 секунд прослушивания; по умолчанию только Wi-Fi. Мобильная сеть и лимит 256 МБ / 512 МБ / 1 ГБ / 2 ГБ настраиваются отдельно.
- Сохранённые треки находятся в «Загружено». Загрузка автокэша идёт, пока играет музыка; частичная загрузка не выдаётся за офлайн-трек. При заполнении лимита освободи место через управление кэшем.
- Шестерёнка → Обновления NUVIA: проверка и скачивание будущих версий прямо в приложении без входа в GitHub. Установку подтверждает Android; при первом обновлении может потребоваться разрешить установку от NUVIA.

Первый переход со старой версии: скачать APK и установить поверх NUVIA. Приложение перед установкой не удалять — это сохранит медиатеку и вход. Android 6.0+.

43 теста прошли, lint без ошибок, сохранена прежняя подпись. Это предварительный выпуск для проверки на телефоне; реальный ВК, фоновые загрузки и системный установщик требуют проверки на устройстве. Исходники остаются в закрытом репозитории.
